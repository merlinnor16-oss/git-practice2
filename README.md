# Персональный сайт-визитка

Проект представляет собой простой персональный сайт с тремя страницами: главная, обо мне и контакты.

## Структура проекта
- `index.html` — главная страница
- `about.html` — страница "Обо мне"
- `contact.html` — страница контактов
- `style.css` — стили для всех страниц
- `README.md` — описание проекта

## Особенности
- Простая и чистая структура HTML/CSS
- Навигация между страницами
- Минимум 5 коммитов с описанием изменений
- Использование дополнительной ветки для разработки новых функций
